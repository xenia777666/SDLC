## Описание проекта

В рамках проекта разрабатывается настольное приложение **«Калькулятор жизни»**.
Пользователь вводит количество лет за компьютером и среднее число часов в день.
На основе этих данных программа вычисляет суммарное время за ПК (в часах и сутках),
оценку пробега курсора, числа кликов мышью и нажатий клавиш.

Приложение должно сохранять введенные данные и восстанавливать
их при повторном открытии диалогового окна. При вводе некорректных значений,
например если число лет вне диапазона 1–120 или часов в день больше 24,
система должна показывать модальное сообщение об ошибке.
