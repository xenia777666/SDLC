# План итераций «Полка»

## Версия 1.0 (после первого раунда с заказчиком)

Длина итерации — 1 неделя. Команда — один разработчик. Срок выпуска MVP — две недели.

| Итерация | Срок | Реализуемый функционал |
|----------|------|------------------------|
| Iteration 1 | 1 неделя | Save book (REQ-FUNC-001), Track current page (REQ-FUNC-002), Finish date (REQ-FUNC-005) |
| Iteration 2 | 1 неделя | Monthly page goal (REQ-FUNC-004) |
| Backlog | после MVP | Filter shelf (REQ-FUNC-003), статус Deferred |

Обоснование сжатия: оценка всех пяти требований — 17 человеко-дней, это больше двух итераций. Фильтр выведен из MVP, потому что без него полка остаётся рабочей.
