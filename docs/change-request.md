# CR-001 Перенос полки на второй компьютер

| Поле | Значение |
|------|----------|
| ID | CR-001 |
| Дата | 09.11.2026 |
| Источник | Заказчик |
| Тип | добавление |
| Срочность | высокий |
| Связанное требование | REQ-FUNC-006 |

## Формулировка

Читатель ведёт полку дома и в университете. `localStorage` на второй компьютер сам не переезжает. Нужна копия, которую можно положить на флешку или в почту файлом.

Ограничения заказчика: дату выпуска MVP не сдвигать, стоимость старшего разработчика не увеличивать.

## Анализ влияния

- Архитектура: новый `BackupPanel`, расширение `LocalStore`, без сервера.
- Трудозатраты: 4 человеко-дня (1 UI + 3 схема и разбор ошибок).
- Срок: в итерацию 2 не помещается, если команду не менять.
- Риски: повреждённый файл, конфликт двух копий.

## Решение

Принято. Дедлайн прежний. В команду на итерацию 2 добавляется junior: он делает кнопки и диалог файла. Senior проверяет JSON и не бросает REQ-FUNC-004.

Взамен REQ-FUNC-003 (фильтр) остаётся Deferred — это уже было согласовано в первом раунде.
