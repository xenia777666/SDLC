# JSON-файл для переноса полки вместо облака

## Контекст и постановка задачи

После старта первой итерации заказчик оформил Change Request: полка нужна и дома, и в университете. `localStorage` к устройству привязан. Дату выпуска сдвигать нельзя, бюджет на облако и старшего разработчика не выделяется.

Вопрос: как перенести полку на второй компьютер, не вводя сервер и не ломая срок MVP?

## Драйверы решения

- REQ-FUNC-006: выгрузить и загрузить копию.
- Запрет сервера и сети из SRS п. 2.3.
- Дедлайн остаётся две недели.
- Junior может сделать кнопки и диалог файла, senior — разбор схемы.

## Рассмотренные варианты

- Облачное хранилище (Google Drive / свой backend)
- Только IndexedDB на каждом компьютере
- JSON-файл через диалог браузера

## Итог решения

Выбранный вариант: «JSON-файл через диалог браузера», потому что он не требует сервера и укладывается в оставшуюся ёмкость итерации 2 при подключении junior-разработчика.

### Последствия

- Хорошо, потому что формат совпадает со снимком `LocalStore`.
- Хорошо, потому что junior закрывает UI, senior не бросает норму месяца.
- Плохо, потому что читатель сам носит файл.
- Плохо, потому что конфликт двух копий разрешается «последняя загрузка побеждает».

### Подтверждение

Демонстрация: сохранить копию, очистить `localStorage`, загрузить файл, полка совпадает. Повреждённый файл полку не меняет. В репозитории нет клиента облака.

## Плюсы и минусы вариантов

### Облачное хранилище

Синхронизация сама.

- Хорошо, потому что два компьютера видят одну полку без файла.
- Плохо, потому что нужен сервер или чужой аккаунт — прямо против SRS.
- Плохо, потому что оценка больше оставшихся дней итерации 2.

### Только IndexedDB

База в каждом браузере.

- Нейтрально, потому что надёжнее localStorage на одном ПК.
- Плохо, потому что между компьютерами ничего не переносит.
- Плохо, потому что не закрывает сам запрос заказчика.

### JSON-файл через диалог браузера

`BackupPanel` + проверка схемы в `LocalStore`.

- Хорошо, потому что нет сети.
- Хорошо, потому что работу можно разрезать: UI junior, схема senior.
- Плохо, потому что это ручной, а не фоновый перенос.

## Дополнительная информация

Адресует REQ-FUNC-006. Затрагивает представления SDD 001-context, 002-composition, 004-information, 005-interaction. Связан с планом итераций версии 1.1.
